DATA FLOW: RCA GRAPH EXAMPLE
=============================

User Action
    ↓
Component (RCAGraphViewer)
    ↓
Hook (useRCAGraph)
    ↓
API Client (client.getRCAGraph())
    ↓
HTTP Request → GET /api/rca/:id/graph
    ↓
Backend RCA Engine
    ↓
HTTP Response ← { success: true, data: { nodes, edges, metadata } }
    ↓
API Client returns response
    ↓
Hook updates state (setGraph)
    ↓
Component re-renders with new data
    ↓
ReactFlow renders graph visualization
    ↓
User sees interactive graph


REAL-TIME UPDATES FLOW
=======================

Backend Event (new insight generated)
    ↓
WebSocket Server sends message
    ↓
WebSocket Client (in AdaptAPIClient)
    ↓
onMessage callback in useInsights hook
    ↓
State updated (setInsights)
    ↓
InsightsPanel component re-renders
    ↓
New insight appears with animation
    ↓
User sees live update


COMPONENT LIFECYCLE
===================

Mount Phase:
1. Component mounts
2. Hook executes useEffect
3. API call initiated (setLoading(true))
4. Response received
5. State updated (setData, setLoading(false))
6. Component renders with data

Update Phase:
1. Props/state change
2. Component re-renders
3. Memoized values recalculated
4. Only changed parts update in DOM

Unmount Phase:
1. Component unmounts
2. Cleanup functions run
3. WebSocket disconnected
4. Event listeners removed
